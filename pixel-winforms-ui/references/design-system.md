# 白底重像素设计规范

## 1. 视觉原则

- 以纯白背景和近黑粗线建立层级，不使用大面积黑底。
- 只使用直角矩形、整数坐标和硬边阴影。
- 像素感来自几何和绘制方式；正文优先保证中文可读性。
- 颜色只表达状态或交互，不承担装饰性渐变。

## 2. 推荐颜色

| 名称 | RGB | 用途 |
|---|---|---|
| Paper | `255,255,255` | 主背景、控件主体 |
| Panel | `246,247,249` | 标题栏、弱分区 |
| Ink | `18,22,28` | 主边框、正文 |
| Muted | `82,91,103` | 次要说明 |
| Grid | `182,188,197` | 硬阴影、禁用态 |
| Blue | `32,107,214` | 焦点、链接 |
| Red | `226,45,59` | 完成、危险、错误 |
| Yellow | `240,177,0` | 等待、警告 |
| Green | `16,157,88` | 运行、成功、选中 |
| PaleBlue | `226,239,255` | 普通悬停底色 |
| PaleGreen | `220,249,232` | 选中底色 |
| PaleRed | `255,226,230` | 危险悬停底色 |

## 3. 字体

- 中文正文：宋体、微软雅黑或产品已有的清晰中文字体，常用 9–10 pt。
- 标题：正文加粗并增加 1–2 pt，不用超大字号。
- 日志和时间：等宽中文字体或系统等宽字体。
- 不把低可读性的像素字体用于长段正文、日志和操作说明。
- 同一层级只使用一套字号和字重。

## 4. 网格与边框

- 窗口外框：6 px。
- 标题栏分隔线：4 px。
- 内容卡片外框：3 px。
- 控件焦点框：2 px。
- 硬阴影偏移：4–6 px，不使用模糊。
- 基础间距：6、8、12、16、20、24 px。
- 所有位置和尺寸使用整数，不在绘制前缩放成小数坐标。

## 5. 窗口

- 推荐最大客户区：`760×438`。
- 小弹窗：`400×152`；长文本弹窗可扩到 `500×230`。
- 进度窗口：约 `440×170`。
- 内容不足时缩小窗口，不保留大片无意义留白。
- 超出固定窗口容量时使用“更多”、分页或像素滚动区。
- 无边框窗口必须具备关闭入口、拖动区域、键盘取消和屏幕边界修正。

## 6. 布局

- 标题栏左侧可放三色像素标识，中间放标题，右侧放关闭或更多按钮。
- 设置页优先使用两栏，分栏线与外框同一体系。
- 概览卡宽高一致；列表行高一致；同组按钮宽高一致。
- 按钮之间保持至少 8 px 间距，避免连续小按钮难以点击。
- 能居中的窗口标题、按钮文字、短状态和空态提示居中。
- 列表名称、项目、阶段、日志和长说明左对齐。

## 7. 状态颜色

- 绿色只表示正在运行、已选中或成功。
- 黄色只表示等待用户、警告或需要处理。
- 红色只表示完成、失败、危险操作或错误。
- 灰色表示空闲、不可用、失联或来源不可信。
- 同时存在多个状态时，先定义聚合优先级，再确定颜色；不要让后到的低优先级状态覆盖高优先级状态。

## 8. 图标

- 应用 EXE、窗口、任务栏、托盘和安装程序使用同一主图标。
- 图标使用整数像素、硬边和有限色板。
- 为 16、20、24、32、48、64、128、256 px 检查可读性。
- 禁止在某些窗口回退为系统默认图标而其他窗口使用品牌图标。
